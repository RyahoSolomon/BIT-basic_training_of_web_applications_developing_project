  第五关判胜时，集齐两条线索会把隐藏关从未解锁提升到已解锁。浏览器已验证首次解锁和已通关后重打两条路径。从胜利页进入剧情后，隐藏关仍保留各自的状态。

- [ ] **40 · 第五关真灵出生格全部被占时只召唤一只**

  四个出生格都有单位时，召唤语句位于查找占位者的循环内。占位者在单位数组首位会漏召，在第三位会在同一格生成两只。应先找到选中格的存活单位并将其移至合法空格，再召唤一次。验收时变换占位者的数组顺序，核对新增真灵数始终为一，两个单位各占一格。

  相关位置：[真灵召唤与移位](../game/battle/scripts/control.js)、[出生格配置](../game/battle/scripts/units-update.js)。

- [ ] **41 · 地形与阵眼效果应作用于格内的存活单位**

  死亡单位仍保留原坐标。如果它在数组里排得较早，地裂会先找到死者并结束搜索，后来走进同一格的活人因而免伤。火焰、震雷和兑泽也使用相同的查找方式。验收时让活人进入死者所在格，核对火焰伤害、地裂致死和两种阵眼的解除结果，并交换数组顺序再测一次。

  相关位置：[地形与阵眼](../game/battle/scripts/class-items.js)、[轮末结算](../game/battle/scripts/control.js)。

- [ ] **42 · 浏览器后退恢复剧情页后可以继续阅读和跳过**

  通过 HTTP 打开序章，跳过到地图后按浏览器后退。命中前进后退缓存时，恢复的页面保留了离开标记，推进与跳过都会失效。验收时在节点剧情和线性剧情中分别确认页面确实从缓存恢复，再验证点击、键盘推进和跳过。

  相关位置：[节点播放器](../src/story/graph-player.jsx)、[线性播放器](../src/story/player.jsx)。

- [x] **43 · 防止旧战斗结算覆盖另一标签页的新存档**

  新开游戏和导入存档时生成新的存档标识。战场在进入时记住标识，写回进度时进行核对。存档已更换时，旧战场结束本场战斗并提供返回主菜单的入口，离开时保留新档。

  已用 Chrome 双标签页分别验证同名新游戏和导入存档。旧标签页结算第五关并离开后，从主菜单继续，角色等级、经验、隐藏线索、关卡和成就均与新档一致。[存档逻辑](../game/shared/scripts/progress.js)、[战斗结算](../game/battle/scripts/battle-settlement.js)、[双标签页回归测试](../scripts/smoke-settlement.cjs)。
